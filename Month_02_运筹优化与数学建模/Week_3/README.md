## 学习内容

域、约束传播；Interval、NoOverlap、Cumulative、可选区间；整数时间缩放；CP-SAT 状态。

## 项目任务

建立同机互斥与累计资源模型；将一个单机模型写成 CP-SAT；校验解与原始约束。

代码归属：optimization_models。项目目录见 [projects](../../projects/README.md)。

## 实验任务

添加维护区间或资源容量后比较排程；改变时间粒度并报告离散化误差。

每项实验保存问题假设、实例或生成种子、算法参数、预算、合法性结果、目标值与运行成本。笔记记录概念、公式、结果及限制，不记录学习时长或日程口号。

## 验收标准

区分 CP 与 MILP 表述；可选任务的选择与时间关联正确；UNKNOWN/INFEASIBLE 不混淆。

# 动态调度综合案例

[项目总览](../README.md) · [学习路线](../../LEARNING_PLAN.md)

对应第 21～24 周。本目录是项目任务框架，尚无求解代码，不能作为已实现成果运行。

## 任务主线

场景与状态 → 滚动时域 → 事件修复 → 离线回放与交付。

## 输入输出与边界

输入为带时间戳的事件和当前状态；输出下一阶段决策、排程变化与指标。不得预读未来事件。

## 首个实现任务

在 shop_scheduling 或 routing 中选择一个已验证静态模型作为后端，动态层不复制算法。

## 交付

可复现实例、模型说明、至少一个基线、独立可行性校验、比较实验及运行文档。源码与实验在实施时增量加入本目录；依赖版本届时记录。

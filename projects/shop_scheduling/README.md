# 多工序与资源约束调度

[学习路线](../../LEARNING_PLAN.md)

对应第 3 月（M3）；第 5 月（M5）可作为主问题。本目录是项目任务框架，尚无求解代码，不能作为已实现成果运行。

## 任务主线

Flow Shop 解码 → JSP 图与 CP → FJSP 选择机器 → RCPSP 资源容量。

## 输入输出与边界

输入含工艺路线、可选机器、加工时间；输出逐工序排程；校验器独立检查前置、资格和资源约束。

## 首个实现任务

建立领域 Operation/Instance，再实现解码与校验，不复制 search_lab 的单机 Job 作为多工序模型。

## 交付

可复现实例、模型说明、至少一个基线、独立可行性校验、比较实验及运行文档。源码与实验在实施时增量加入本目录；依赖版本届时记录。

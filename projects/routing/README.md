# 网络优化与车辆路径

[学习路线](../../LEARNING_PLAN.md)

对应第 4 月（M4）；第 5 月（M5）可作为主问题。本目录是项目任务框架，尚无求解代码，不能作为已实现成果运行。

## 任务主线

网络流/指派 → TSP → CVRP → VRPTW。

## 输入输出与边界

输入含节点、距离/时间、车辆、容量与窗口；输出路线及服务时间；校验访问覆盖、容量和时间递推。

## 首个实现任务

先写小型网络与路线实例，后加入构造和精确模型。复用搜索机制时显式提供路线邻域与评价。

## 交付

可复现实例、模型说明、至少一个基线、独立可行性校验、比较实验及运行文档。源码与实验在实施时增量加入本目录；依赖版本届时记录。

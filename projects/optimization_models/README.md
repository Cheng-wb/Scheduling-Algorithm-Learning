# LP / MILP / CP 模型实验

[学习路线](../../LEARNING_PLAN.md)

对应第 2 月（M2，Week 1–4）。本目录是项目任务框架，尚无求解代码，不能作为已实现成果运行。

## 任务主线

生产计划与运输 LP → 整数模型与松弛 → 区间与累计资源 → 精确方法比较。

## 输入输出与边界

输入为参数与约束；输出包含求解状态、可行解、目标、上下界与耗时。对偶信息仅用于适用的连续模型。

## 首个实现任务

从第 2 月 Week 1 的生产计划 LP 开始，建立 models、solvers、experiments 与 results；在第一份实现时再确定模块细分。

## 交付

可复现实例、模型说明、至少一个基线、独立可行性校验、比较实验及运行文档。源码与实验在实施时增量加入本目录；依赖版本届时记录。

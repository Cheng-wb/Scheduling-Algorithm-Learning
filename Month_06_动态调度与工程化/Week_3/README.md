# Week 3：工程接口与离线回放（全程第 23 周）

[月度大纲](../README.md) · [六个月总览](../../LEARNING_PLAN.md)

## 学习内容

输入契约、版本、随机性、日志、限时、取消与降级；API/CLI 边界；可复现实验产物。

## 每日计划

| 日期 | 主题 | 学习与实践任务 | 交付 / 完成标准 |
| --- | --- | --- | --- |
| Day 1 | 输入输出契约 | 固定实例、事件、配置与结果版本，定义错误状态 | 字段说明与最小样例 |
| Day 2 | 稳定 CLI | 整理运行参数、限时、种子与结果目录 | 一条命令运行离线案例 |
| Day 3 | 薄 API 接口 | 用 FastAPI 包装现有调用，处理请求校验与结果状态 | API 层不复制求解逻辑 |
| Day 4 | 日志与降级 | 记录每次输入配置、耗时和状态，明确超时/取消/失败处理 | 一次失败可以从日志定位 |
| Day 5 | 可复现环境 | 用 Docker 固定运行环境，验证必要 Linux 启动命令；按需决定是否使用 SQL | 干净环境可启动最小案例 |
| Day 6 | 异常回放 | 运行非法输入、不可行、无资源、超时等案例 | 返回状态正确且服务不会伪报成功 |
| Day 7 | 工程交付整理 | 核对 CLI/API 与离线结果一致，整理部署与运行说明 | 算法仍可脱离服务独立运行 |

按上述顺序推进；已有实现用于复核和补缺，不重复编写。每日交付记录在相应实验或主题笔记中，本计划不预建每日笔记文件。

## 项目任务

提供稳定 CLI 与薄 FastAPI 接口；用 Docker 记录运行环境，Linux 命令按部署需要使用；SQL 仅在需要持久化任务时加入，不单开工具基础课。

代码归属：dynamic_scheduling。项目目录见 [projects](../../projects/README.md)。

## 实验任务

从干净环境运行最小案例；异常输入、不可行、无可用资源、超时回放；与静态基线核对。

每项实验保存问题假设、实例或生成种子、算法参数、预算、合法性结果、目标值与运行成本。笔记记录概念、公式、结果及限制，不记录学习时长或日程口号。

## 验收标准

一条命令复现核心结果；失败有明确状态；算法不依赖服务层，日志可追溯到配置和实例。

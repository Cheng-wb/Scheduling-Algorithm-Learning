# Week 3：工程接口与离线回放（全程第 23 周）

[月度大纲](../README.md) · [六个月总览](../../LEARNING_PLAN.md)

## 学习内容

输入契约、版本、随机性、日志、限时、取消与降级；API/CLI 边界；可复现实验产物。

## 项目任务

提供稳定 CLI 与薄 FastAPI 接口；用 Docker 记录运行环境，Linux 命令按部署需要使用；SQL 仅在需要持久化任务时加入，不单开工具基础课。

代码归属：dynamic_scheduling。项目目录见 [projects](../../projects/README.md)。

## 实验任务

从干净环境运行最小案例；异常输入、不可行、无可用资源、超时回放；与静态基线核对。

每项实验保存问题假设、实例或生成种子、算法参数、预算、合法性结果、目标值与运行成本。笔记记录概念、公式、结果及限制，不记录学习时长或日程口号。

## 验收标准

一条命令复现核心结果；失败有明确状态；算法不依赖服务层，日志可追溯到配置和实例。

# Week 2：JSP 的图表示与精确模型（全程第 10 周）

[月度大纲](../README.md) · [六个月总览](../../LEARNING_PLAN.md)

## 学习内容

析取图、机器顺序与工序优先关系；关键路径、环与不可行性；JSP 的 interval 表述。

## 项目任务

实现 JSP CP-SAT、实例读取与独立校验；生成基于可执行工序集合的派工基线。

代码归属：shop_scheduling。项目目录见 [projects](../../projects/README.md)。

## 实验任务

小实例精确求解，较大实例限时；对比派工基线、目标、下界、gap 和甘特图。

每项实验保存问题假设、实例或生成种子、算法参数、预算、合法性结果、目标值与运行成本。笔记记录概念、公式、结果及限制，不记录学习时长或日程口号。

## 验收标准

每道工序恰执行一次；前置与机器互斥均满足；不会直接交换工序后忽略环。

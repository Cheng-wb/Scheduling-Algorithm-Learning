## 1. 为什么需要第二个模型

生产方案只能告诉我们“至少能赚多少”。要证明方案最优，还需要一个“最多能赚多少”的上界。对偶模型把资源赋予价格，用资源总价值控制所有生产方案的利润。

## 2. 从不等式推导，而不是先背表

原始问题取 $\max c^Tx$，约束 $Ax\le b,x\ge0$。选非负资源价格 $y\ge0$，要求每项活动消耗的资源价值不低于其利润，即 $A^Ty\ge c$。对于任意原始可行 $x$：

$$c^Tx\le y^TAx\le y^Tb.$$

第一步来自 $x\ge0,A^Ty\ge c$；第二步来自 $y\ge0,Ax\le b$。于是 $b^Ty$ 是所有可行利润的上界。寻找最紧的此类上界，就得到对偶：

$$\min b^Ty\quad\text{s.t. }A^Ty\ge c,\ y\ge0.$$

这同时证明了弱对偶。强对偶进一步说明：LP 原始问题可行且最优值有限时，对偶也有最优解，两边最优值相等。强对偶是 LP 的定理，不是从上面两步不等式直接推出的。

## 3. 用第一天的模型算出证书

对偶为：

$$\min100y_1+80y_2$$
$$2y_1+y_2\ge40,\qquad y_1+2y_2\ge30,\qquad y_1,y_2\ge0.$$

取 $y=(50/3,20/3)$，两条约束都取等号，对偶目标为 2200。原始可行点 $(40,20)$ 的利润也是 2200。弱对偶把最优值夹在二者之间，因此这对解已经构成完整的最优性证明。

## 4. 互补松弛从 gap 分解得到

对任意原始、对偶可行解：

$$b^Ty-c^Tx=y^T(b-Ax)+x^T(A^Ty-c).$$

右侧每项非负。总 gap 为零，当且仅当各项都为零：

$$y_i(b_i-a_i^Tx)=0,\qquad x_j((A^Ty)_j-c_j)=0.$$

资源有剩余时，对应对偶价格必须为零；产品正产量时，对应单位利润等于按对偶价格计量的资源消耗。反方向要谨慎：资源刚好用完，价格仍可能为零；检验数为零，产量仍可能为零。

## 5. 约束符号与自由变量

以下表格针对**最大化原始问题**；最小化模型可先取负目标或单独推导。

| 原始对象 | 对偶中的对应要求 |
|---|---|
| 一条 $\le$ 约束 | 对偶变量 $y_i\ge0$ |
| 一条 $\ge$ 约束 | 对偶变量 $y_i\le0$ |
| 一条等式 | 对偶变量自由 |
| 变量 $x_j\ge0$ | 对偶约束 $(A^Ty)_j\ge c_j$ |
| 变量 $x_j\le0$ | 对偶约束 $(A^Ty)_j\le c_j$ |
| 变量 $x_j$ 自由 | 对偶约束取等号 |

有限上下界也是约束，有对应对偶作用。项目中为了便于构造对偶，把某些上界写成显式行；这是一种实现选择，不是数学上禁止使用变量上界。

## 6. 实验与自测

运行脚本前先独立写对偶，再检查双方可行性、目标相等和互补松弛。只检查目标相等不够：两个不可行点也可能数值相等。

1. 对偶可行解能给最大化原始问题什么界？上界。
2. 原始无界时，对偶还能可行吗？不能，否则弱对偶提供有限上界，与无界矛盾。
3. 原始不可行能推出对偶无界吗？不能，对偶也可能不可行。

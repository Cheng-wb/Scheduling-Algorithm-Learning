# 第二个月零基础教材：从运筹建模到精确调度

这套材料面向**没有学过运筹学的人**。正文从数学符号和业务翻译讲起，不要求你已经知道对偶、整数规划或求解器术语。每章都包含解释、推导、完整算例与有过程的练习解答。

## 从哪里开始

第一次学，请按下面 **第 0–7 章**连续阅读。先完成纸笔算例，再运行教学程序；读不懂一个符号时回到第 0 章，不需要先去背一套接口。

知识顺序是：**数学语言 → LP → 对偶 → 0-1 规划 → MILP → CP-SAT → 求解器工程 → 综合实训**。0-1 规划单独成章，先掌握背包、指派、覆盖和逻辑选择，再学习调度里的排序变量。

## 怎样使用例题和练习

正文中的完整例题负责教方法，章末练习负责检查是否能自己做。先盖住解答写出变量、约束和计算，再对照每一步；只得到相同数字而说不清原因，还没有完成这道题。

教材使用几个反复出现的小问题：两产品生产计划贯穿 LP、对偶和敏感性；三作业单机问题贯穿枚举、MILP、CP-SAT；并行机例子逐步加入工人资源。每次增加一个新概念，让你知道结果究竟因为什么变化。

## 运行教学算例

前半部分只用 Python 标准库，可分别运行：

```powershell
python -X utf8 "Month_02_精确算法与参数学习/教材/examples.py" lp
python -X utf8 "Month_02_精确算法与参数学习/教材/examples.py" binary
python -X utf8 "Month_02_精确算法与参数学习/教材/examples.py" schedule
```

学习到求解器章节后，按[项目指南](../projects/02_optimization_models/PROJECT_GUIDE.md)配置 OR-Tools，再运行：

```powershell
python -X utf8 "Month_02_精确算法与参数学习/教材/examples.py" all
```

`milp`、`cp` 可以单独运行。程序同时检查数学预期和排程规则；预计数值、依赖和核验范围见[运行与核验说明](教材/运行与核验说明.md)。它不覆盖原项目的历史实验，也不写入历史 artifacts。

## 学完的标准

能从空白纸写出一个简单模型；能讲清约束为什么这样写；能手算小例并解释最优性依据；能运行并验证一个 MILP 和 CP-SAT 模型；能区分“有方案”“未获结论”“子问题最优”和“原问题已证最优”。第 7 章提供完整实训和解答，供你逐项检查。

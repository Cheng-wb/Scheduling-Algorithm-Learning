# 第 2 月：MILP、CP-SAT 与求解器诊断

本月目标：理解精确求解器为什么快或慢，能够强化模型、读取求解状态，并用实验选择模型和参数。

## 月末验收

- 能解释目标值、下界、gap、超时和不可行冲突。
- 至少两个模型强化约束带来可测的求解改进。

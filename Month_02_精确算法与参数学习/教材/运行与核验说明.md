# 教学程序：运行方式与核验范围

[教材目录](../README.md) · [教学程序源码](examples.py)

## 1. 从哪里运行

命令假设当前目录为仓库根目录。程序不读取你的业务数据，也不覆盖历史实验目录。需要 Python；`lp`、`binary`、`schedule` 仅使用标准库，`milp` 和 `cp` 另外需要 OR-Tools。

```powershell
python -X utf8 "Month_02_精确算法与参数学习/教材/examples.py" all
```

`-X utf8` 使重定向输出时也使用 UTF-8，减少 Windows 环境中的中文编码差异。若依赖缺失，请参照[项目安装说明](../../projects/02_optimization_models/PROJECT_GUIDE.md)，使用选定的 Python 环境安装项目要求的依赖。

## 2. 各入口教什么

| 入口 | 数学内容 | 应得到的关键结果 |
|---|---|---|
| `lp` | 枚举二维顶点、检查原始与对偶、扰动资源 | 原始利润 2200；对偶价格 50/3、20/3 |
| `binary` | 背包、覆盖、逻辑真值表、综合选择 | 背包收益 7；覆盖费用 5；综合订单收益 8 |
| `schedule` | 六个单机顺序及受限子问题 | 原最优迟交 2；固定 C 第一后为 3 |
| `milp` | 连续时间 Big-M MILP 与 LP 松弛 | MILP 目标 2；LP 松弛下界 0 |
| `cp` | 单机、并行机、JSP、工人容量 | 总迟交 2；工期分别 4、5、7 |
| `all` | 依次运行以上全部 | 所有教学检查通过 |

最优排程不要求与某次输出逐项相同；允许存在不同最优排程。目标、约束与证书范围才是主要检查对象。

## 3. 如何阅读程序

先看 `production_vertices` 和 `schedule_examples`，它们通过很小的完整候选集合得到独立答案。再看 `milp_examples` 与 `cp_single`，对照教材中的每一条数学约束。之后读并行机和 JSP，最后看 `validate_schedule` 如何独立检查输出。

二维顶点枚举不是通用 LP 求解器，0-1 全枚举也不适用于很大实例。这里选择简单算法，是为了让读者能核对求解器之外的参考结果。

## 4. 本次核验记录

核验环境：Python 3.14.6、OR-Tools 9.15.6755。完整运行包含：

- 用有理数核对生产 LP、对偶和 201 个机器资源取值的分段敏感性公式。
- 枚举背包、集合覆盖与综合订单选择；核对逻辑真值表与包含负下界的乘积线性化。
- 枚举全部六种单机顺序；核对固定前缀改变最优值的反例。
- 实际求解 CBC MILP 和 GLOP LP 松弛，分别得到目标 2 与 0。
- 实际求解四个 CP-SAT 小模型，并检查任务完整性、工时、机器互斥、工序先后、工人容量和重算目标。

此外已运行第 5 章完整 Python 示例，核对 42 份入口/教材/配套文档中的 404 个本地链接，并检查三张示意图。这里没有重新运行旧项目的性能批次；毫秒耗时、节点数和线程表现不是本次教材验收指标。

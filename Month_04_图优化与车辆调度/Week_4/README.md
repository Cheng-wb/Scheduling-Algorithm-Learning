# Week 4：VRPTW 与路线项目验收（全程第 16 周）

[月度大纲](../README.md) · [六个月总览](../../LEARNING_PLAN.md)

## 学习内容

行驶、等待、服务时间；时间窗作用于服务开始；车辆可用区间；硬/软时间窗与字典序目标。

## 项目任务

扩展 Routing 时间维度、时间窗校验和时间线输出；统一成本与车辆数优先级。

代码归属：routing。项目目录见 [projects](../../projects/README.md)。

## 实验任务

小例手算到达/开始/离开时间；松紧时间窗多实例比较；分析可行率与路线质量。

每项实验保存问题假设、实例或生成种子、算法参数、预算、合法性结果、目标值与运行成本。笔记记录概念、公式、结果及限制，不记录学习时长或日程口号。

## 验收标准

时间递推与窗口无误；不同目标定义不混比；交付 CVRP/VRPTW 报告与可复现实例。

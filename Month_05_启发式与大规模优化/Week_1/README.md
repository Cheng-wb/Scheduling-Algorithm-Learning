# Week 1：结构化邻域与增量评价（全程第 17 周）

[月度大纲](../README.md) · [六个月总览](../../LEARNING_PLAN.md)

## 学习内容

选一个主问题；关键块或 relocate/exchange/2-opt；可行性保持；增量目标与缓存失效。

## 项目任务

在 FJSP 或 VRPTW 上实现两个有效邻域；为一个算子实现增量评价并保留全量复核路径。

代码归属：shop_scheduling 或 routing（选择一个主问题）。项目目录见 [projects](../../projects/README.md)。

## 实验任务

随机可行解与 Move 上逐次核对增量/全量差值；比较每次评价时间和搜索收益。

每项实验保存问题假设、实例或生成种子、算法参数、预算、合法性结果、目标值与运行成本。笔记记录概念、公式、结果及限制，不记录学习时长或日程口号。

## 验收标准

邻域不靠漏任务改善分数；增量计算与全量一致；性能提升不改变目标含义。

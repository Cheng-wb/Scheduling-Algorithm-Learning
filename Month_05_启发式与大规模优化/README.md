## 月度交付

一个经过等预算、多实例评测的混合求解器及消融报告。

项目归属：shop_scheduling 或 routing（选择一个主问题）。每月沿用已有项目增量扩展，不复制上一周的基础代码。不要求预先实现后续月份算法。

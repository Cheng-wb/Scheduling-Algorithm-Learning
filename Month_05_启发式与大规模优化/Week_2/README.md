## 学习内容

扰动、局部下降、邻域切换；禁忌属性、期限和特赦；多起点与路径记忆的区别。

## 项目任务

主线实现 ILS/VNS 之一并与已有 LS/SA 比较；Tabu 用小实验理解，GA 了解编码、交叉与修复，不同时实现完整 GA。

代码归属：shop_scheduling 或 routing（选择一个主问题）。项目目录见 [projects](../../projects/README.md)。

## 实验任务

同评价或时间预算、多实例多种子；比较扰动强度或邻域顺序；记录探索失败案例。

每项实验保存问题假设、实例或生成种子、算法参数、预算、合法性结果、目标值与运行成本。笔记记录概念、公式、结果及限制，不记录学习时长或日程口号。

## 验收标准

改善归因到具体机制；参数选择与最终评测实例分离；预算记录真实完整。

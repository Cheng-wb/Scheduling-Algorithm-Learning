# Week 3：LNS、ALNS 与破坏修复（全程第 19 周）

[月度大纲](../README.md) · [六个月总览](../../LEARNING_PLAN.md)

## 学习内容

Destroy/Repair；随机与相关移除；贪心/后悔插入；算子权重、自适应更新与接受策略。

## 项目任务

实现两个破坏、两个修复算子，先固定选择概率再增加自适应权重；保留最佳可行解。

代码归属：shop_scheduling 或 routing（选择一个主问题）。项目目录见 [projects](../../projects/README.md)。

## 实验任务

消融无自适应/无某算子/不同破坏率；比较可行率、质量和耗时，不仅展示最好一次。

每项实验保存问题假设、实例或生成种子、算法参数、预算、合法性结果、目标值与运行成本。笔记记录概念、公式、结果及限制，不记录学习时长或日程口号。

## 验收标准

移除任务全部被修复或明确失败；权重更新不数值失控；优于基线的结论有配对数据。
